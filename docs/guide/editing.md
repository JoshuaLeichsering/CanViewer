> [!NOTE]
> Editing is not in this version of CanViewer yet. This page describes what is
> planned.

Planned, in two steps:

1. A DBC writer that writes a database back out without changing what it means: for
   every real-world database CanViewer is tested against, reading the written file
   must give the same model as reading the original.
2. Editing the properties of messages and signals, and saving the result as a DBC file.
